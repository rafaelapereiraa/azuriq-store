## 2. Sobre a loja

A Azuriq Store é uma loja fictícia de acessórios. O projeto permite que o usuário escolha quantidades de produtos e simule o valor de uma compra.

### Produtos disponíveis

| Produto        | Descrição                        |    Preço |
| -------------- | -------------------------------- | -------: |
| Colar Delicado | Acessório minimalista e elegante | R$ 39,90 |
| Óculos de Sol  | Modelo moderno para o cotidiano  | R$ 59,90 |
| Bolsa Casual   | Prática e ideal para o dia a dia | R$ 89,90 |

O simulador oferece 10% de desconto para compras a partir de R$ 150,00.

## 3. Tecnologias utilizadas

- HTML: estrutura da página.
- CSS: aparência e organização visual.
- JavaScript: cálculos e funcionamento da simulação.

## 4. Como executar

1. Baixe ou abra os arquivos do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Clique em **Simular compra**.
4. Informe as quantidades desejadas de cada produto.
